# 🤖 JARVIS AI AGENT — এন্টারপ্রাইজ সিস্টেম আর্কিটেকচার ও ডেভেলপার গাইডলাইন

> **পবিত্র নিয়ম (Golden Rule):** এই প্রজেক্টটি (`Jarvis_AI_Agent`) সম্পূর্ণ স্বতন্ত্র ও স্বাধীন। এটি কখনোই মূল ইআরপি (`Web_ERP` বা `Web_ERP_Client`)-এর কোনো সোর্স কোড মডিফাই বা পরিবর্তন করবে না। যে কোনো ভবিষ্যতের এআই এজেন্ট বা ডেভেলপারকে এই গাইডলাইনের প্রতিটি শর্ত ১০০% কঠোরভাবে মেনে চলতে হবে।

## ১. সিস্টেম দর্শন ও মূল লক্ষ্য (System Philosophy)
১. **মালিকের বিশ্বস্ত পার্সোনাল অ্যাসিস্ট্যান্ট**: সিস্টেমটি একজন মানব অ্যাসিস্ট্যান্টের মতো স্বাভাবিক, মার্জিত ও খাঁটি বাংলাদেশী বাংলায় কথা বলবে এবং কাজ করবে।
২. **অ্যাডাপ্টিভ মেমোরি (Adaptive Learning)**: মালিকের পছন্দ, নির্দেশ ও ব্যবসায়িক নিয়মগুলো সময়ের সাথে সাথে শিখে মনে রাখবে এবং কাজের সময় তা স্বয়ংক্রিয়ভাবে স্মরণ করবে।
৩. **মডুলার ও প্লাগ-এন্ড-প্লে আর্কিটেকচার**: নতুন কোনো ব্যবসার খাতা বা কাজ যুক্ত করতে চাইলে মূল সিস্টেমে হাত না দিয়ে শুধুমাত্র একটি নতুন স্কিল ফাইল (`skill_*.js`) যোগ করলেই চলবে।
৪. **আর্থিক নিরাপত্তা (Financial Integrity)**: কোনো লেনদেন বা হিসাবের পরিবর্তন নিশ্চিতকরণ ছাড়া করবে না। প্রাথমিকভাবে সমস্ত অ্যাকশন নিরাপদ রিড-অনলি ও ড্রাফট হিসেবে চলবে।

## ৩. নতুন স্কিল তৈরির স্ট্যান্ডার্ড চুক্তি (Skill Creation Contract)

যে কোনো নতুন ফিচার যুক্ত করার সময় ডেভেলপার বা এজেন্টকে `BaseSkill` ইনহেরিট করে তৈরি করতে হবে:

```javascript
import { BaseSkill } from './base_skill.js';

export class MyNewSkill extends BaseSkill {
    constructor() {
        super({
            id: 'my_skill_id',
            name: 'স্কিলের বাংলা নাম',
            description: 'এই স্কিলটি কী কাজ করে তার সংক্ষিপ্ত বিবরণ',
            triggers: ['ট্রিগার ১', 'ট্রিগার ২'] // ভয়েস কিওয়ার্ড
        });
    }

    // এআই এর জন্য টুল/ফাংশন ডেফিনিশন
    getTools() {
        return [{
            name: 'execute_my_skill',
            description: 'টুলের স্পষ্ট কার্যপ্রণালী',
            parameters: { ... }
        }];
    }

    // মূল লজিক এক্সিকিউশন
    async execute(actionName, params, context) {
        // ডেটা ফেচিং ও প্রসেসিং
        return {
            success: true,
            spokenResponse: 'মালিককে মুখে শোনানোর জন্য মিষ্টি বাংলা উত্তর',
            displayData: { ... } // স্ক্রিনে দেখানোর জন্য ডেটা
        };
    }
}
```

## ৪. দীর্ঘমেয়াদী স্মৃতিভাণ্ডার প্রোটোকল (Memory Vault Protocol)

জার্ভিসের মেমোরি ৩টি সুনির্দিষ্ট ভাগে ফায়ারস্টোরের `ai_memory` কালেকশনে সংরক্ষিত থাকে:
1. **Fact Memory (তথ্য)**: প্রতিষ্ঠানের তথ্য (যেমন: পার্টনারদের নাম, প্রধান ব্যাংক অ্যাকাউন্ট, দুবাই ইনচার্জ)।
2. **Preference Memory (পছন্দ)**: মালিক কীভাবে কথা শুনতে চান, কোন রিপোর্ট আগে চান, কোন ফরম্যাটে প্রিন্ট চান।
3. **Rule Memory (নিয়মকানুন)**: ব্যবসার বিশেষ নিয়ম (যেমন: *"বৃহস্পতিবার দুবাই হিসাবের দিন"*, *"বকেয়া ৫০ হাজারের বেশি হলে সতর্কবার্তা"* )।

প্রতিটি কথোপকথনের সময় `MemoryVault.getContextPrompt()` কল করে এআই এর ব্রেইনে প্রাসঙ্গিক স্মৃতিগুলো ইনজেক্ট করা হয়।

## ৫. বাংলা নিউরাল ভয়েস স্ট্যান্ডার্ড (Bangladeshi Voice Standards)
- **উচ্চারণ মান**: সর্বদা খাঁটি বাংলাদেশী প্রমিত বাংলা (Bangladeshi Native Accent - `bn-BD`) নিশ্চিত করতে হবে। কোনো ভারতীয় বাংলা বা রোবোটিক টোন দেওয়া যাবে না।
- **মিশ্র শব্দ হ্যান্ডলিং**: হিসাবের ক্ষেত্রে "ক্যাশ", "কালেকশন", "ব্যাংক ব্যালেন্স", "এল/সি", "মেমো" শব্দগুলো বাংলা বাক্যের মাঝে সাবলীলভাবে উচ্চারণ করবে।
- **টাকার অঙ্ক কথায় রূপান্তর**: যেকোনো বড় আর্থিক অঙ্ক বলার সময় বাংলায় প্রাঞ্জলভাবে বলবে (যেমন: *"পাঁচ কোটি আটান্ন লক্ষ টাকা"* )।

## ৬. হিসাববিজ্ঞান ও পরিভাষা নীতি (Accounting Terminology)
- **'জের' শব্দ নিষিদ্ধ**: কখনোই "জের" বলা যাবে না। সর্বদা **"ব্যালেন্স"**, **"অবশিষ্ট বকেয়া"** বা **"স্থিতি"** বলতে হবে।

  - জমা / ক্রেডিট (Credit) = **সবুজ (Emerald / #10b981)**
  - খরচ / বিল / ডেবিট (Debit) = **লাল (Red / #ef4444)**
  - ব্যালেন্স / স্থিতি = **নীল / সাইয়ান (#06b6d4 / #0284c7)**
